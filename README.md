💪 Muscu Tracker

Application web de suivi de séances de musculation, pensée pour être utilisée sur téléphone, directement depuis la salle.

Capture d'écran


Fonctionnalités
Création d'une séance : date, nom, partenaire d'entraînement, exercices classés par groupe musculaire
Saisie des séries en kg × répétitions, avec séries d'échauffement, poids du corps et séries enchaînées à charge dégressive
Regroupement d'exercices en bisets, réordonnables par glisser-déposer
Séances types réutilisables
Fil d'historique des séances, modifiables après coup
Records par exercice (estimation du 1RM)
Courbes de progression par exercice
Thème clair / sombre automatique
Technologies

HTML, CSS et JavaScript pur (un seul fichier, aucune dépendance). Les données restent dans le navigateur (localStorage) : rien n'est envoyé sur un serveur.

Lancer le projet

Ouvrir index.html dans un navigateur. Aucune installation.

Limites et pistes d'amélioration
Les données sont stockées uniquement sur l'appareil utilisé (pas de synchronisation entre appareils)
À ajouter : export / import des données, graphiques de volume par semaine
